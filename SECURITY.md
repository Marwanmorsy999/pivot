# Security Policy

## Supported Versions

We actively maintain the latest release and provide security patches for the following versions:

| Version | Supported          | Notes |
|---------|-------------------| -------|
| 2.1.x   | :white_check_mark: | Current stable release |
| 2.0.x   | :x:                | Upgrade to 2.1.x recommended |
| < 2.0   | :x:                | No longer supported |

## Reporting a Security Vulnerability

If you discover a security vulnerability in PIVOT, please report it responsibly.

**Do NOT open a public issue for security vulnerabilities.**

Instead, please report via:
- Open a [private security advisory](https://github.com/Marwanmorsy999/pivot/security/advisories/new) on GitHub
- Or contact the maintainer directly

Please include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact (data loss, code execution, etc.)
- Suggested fix (if any)
- Your disclosure preferences (anonymous or credited)

### Response Timeline

| Stage | Timeframe |
|-------|-----------|
| Initial acknowledgment | Within 48 hours |
| Investigation & assessment | Within 7 days |
| Fix development | Within 30 days |
| Public disclosure | Coordinated with reporter |

## Security Best Practices for Users

### API Keys & Credentials

PIVOT stores API keys in `~/.pivot/config.yaml`. Protect this file:

```bash
# Restrict permissions on config file
chmod 600 ~/.pivot/config.yaml

# Restrict permissions on state database
chmod 600 ~/.pivot/state.db
```

**Never commit API keys or credentials to version control.**

### LLM Output Execution

PIVOT executes commands generated by AI planners. Be aware that:

- Task arguments from LLM output are passed directly to `exec.Command`
- Malicious or incorrect LLM output could execute unintended commands
- Always review the task graph before execution when possible
- Use worktree isolation for agent tasks to limit filesystem impact
- Run PIVOT with the minimum necessary privileges

### Network Security

- All HTTP clients have a 60-second timeout to prevent hanging connections
- API keys are sent only to configured endpoints
- No telemetry or analytics data is collected

### Dependencies

PIVOT depends on third-party packages. We regularly review and update dependencies:

```bash
# Check for known vulnerabilities in dependencies
go mod audit

# Update dependencies
go get -u ./...
go mod tidy
```

## Security Features

- **Input validation**: Task arguments are validated before execution
- **Error handling**: All errors are properly handled and logged
- **No secrets in logs**: API keys are never logged or displayed
- **Worktree isolation**: Agent tasks run in isolated git worktrees
- **Timeout protection**: HTTP requests have timeouts to prevent hanging

## Security Checklist for Contributors

- [ ] No hardcoded secrets or credentials
- [ ] All error cases are handled
- [ ] Input validation for external data
- [ ] No SQL injection vulnerabilities (use parameterized queries)
- [ ] No command injection vulnerabilities (avoid shell execution)
- [ ] Dependencies are up-to-date
- [ ] Tests cover security-relevant code paths
